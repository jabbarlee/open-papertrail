# Voice: Ink Line

**`jules`** (Qwen, `voices/jules.wav`): a young adult, light and clear, a little wry, telling a story about their own
week. Temperature 1.0. Without the voice server, Kokoro `af_sarah` speaks.

- `npm run studio -- voice <episode>`: the whole script in one take (3 tries, clearest kept), then re-timed line by
  line so each line's `{pause=…}` lands.
- `pause=` only before the payoff. Numbers as words, no tags, no speed changes.
