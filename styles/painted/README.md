# Painted

Deadpan third-person comedy: the lead runs one ordinary errand where one thing is wrong, and everyone plays it straight.
Gouache-painted sets, flat thin-inked characters, one "photographic" collage prop, all under a painted overlay. 10-32 s.

- **Example:** `examples/candles/` (Otto buys one birthday candle every Saturday) → `../../examples/painted/candles.mp4`
- **Rules:** `FORMAT.md`, `DESIGN.md` (incl. the rules for new characters), `VOICE.md` (`basil`), `MAKE.md`
- **Cast:** Otto (the lead), Mae, Sal, Dex and a cat in `components/cast/`; Otto's sheet in `look/sheet/`. Make your own with `/new-character`.
- **Components:** `components/README.md`
